Data Repository

Your tasks are stored as board.json in a separate personal-todo-data GitHub repository — the app itself requires no API access. Create that repo (it can be private), then generate a Personal Access Token scoped to it with repo scope (or contents: write for fine-grained tokens). Your token is stored only in this browser's localStorage.
