Data Repository

Your tasks are stored as board.json in a separate personal-todo-data GitHub repository — the app itself requires no API access. Create that repo (it can be private), then generate a Personal Access Token scoped to it with repo scope (or contents: write for fine-grained tokens). Your token is stored only in this browser's localStorage.

Disconnect data repo?

This will remove your token and repository settings from this browser. Your data in personal-todo-data will not be affected.

Connect your data repo

You're currently viewing example data. To create, edit, and save your own tasks, connect a private personal-todo-data GitHub repository. See the README for setup instructions.
